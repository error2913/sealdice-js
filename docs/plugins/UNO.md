# UNO

- 目录：[UNO/](https://github.com/error2913/sealdice-js/tree/main/UNO/)
- 扩展名：UNO
- 版本：1.0.1
- 作者：错误
- 依赖：team（>= 4.0.0）

## 简介

TypeScript 编写的 UNO 卡牌插件，使用 team 插件中的成员创建对局。

## 指令

```text
【.uno start】使用team里的成员创建游戏
【.uno end】结束游戏
【.uno check】查看自己的手牌
【.uno skip】跳过这轮
【.uno <牌名> (指定颜色)】出牌
【.uno info】查看游戏信息
```

另有 `万能`、`加四` 等牌堆相关指令。

## 构建

```bash
npm install
npm run build
```
