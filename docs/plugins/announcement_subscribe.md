# 公告订阅版

- 源码：[announcement_subscribe.js](https://github.com/error2913/sealdice-js/blob/main/announcement_subscribe.js)
- 版本：1.0.1
- 作者：错误
- 依赖：无

## 简介

公告频道订阅与发布插件。骰主维护多个频道（每个频道一个正则），用户订阅后即可收到对应公告。使用 `.订阅公告` 查看帮助。

## 指令

```text
.订阅公告 添加 <频道名称> <公告内容正则表达式>
.订阅公告 删除 <频道名称>
.订阅公告 频道列表
.订阅公告 发布 <频道名称> <公告内容>
.订阅公告 订阅 <频道名称>
.订阅公告 取消订阅 <频道名称>
.订阅公告 订阅列表
```

## 配置

数据保存在扩展存储中：`channels` 记录频道名称、正则与订阅用户，`users` 记录每个用户订阅的群与私聊状态。
