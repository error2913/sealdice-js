# animal_world（动物世界）

- 目录：[animal_world/](https://github.com/error2913/sealdice-js/tree/main/animal_world/)
- 扩展名：animalWorld
- 版本：1.0.1
- 作者：错误
- 依赖：无

## 简介

TypeScript 编写的动物养成插件。玩家拥有动物，可进行复活、生存、探索、繁殖、进化等操作，并有分数排行榜。

## 指令

```text
.aw         玩家操作主指令
.revive     复活
.survive    生存
.explore    探索
.multiply   繁殖
.evolve     进化
```

> 提示：各子指令均有对应中文帮助文案。

## 构建

```bash
npm install
npm run build
```
