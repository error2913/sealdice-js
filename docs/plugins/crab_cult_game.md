# 蟹脚小游戏

- 源码：[crab_cult_game.js](https://github.com/error2913/sealdice-js/blob/main/crab_cult_game.js)
- 版本：2.2.1
- 作者：错误
- 依赖：无

## 简介

克苏鲁题材养成小游戏。使用 `.cult` 查看游戏指引，`.cult master` 查看骰主指令。

经验值：翻垃圾、遭遇警察/神话生物、强行越狱成功、献祭成功、抢劫以及战胜等级高的对手可获得更多。贡献值越高，发展信众获得的货币越高；达到上限献祭成功后可晋升职位。抢劫成败与等级、武器数值挂钩，同时具有随机性；市场买卖多次后各地物价会逐渐持平。

## 主要指令

```text
.cult / .cult master   游戏指引 / 骰主指令
.加入 教团             加入教团（可用 .教团信息 查看，或 .加入 随便）
.今日商店 （地点）     查看商店
.查看背包 / .清除背包  查看/清理背包
.前往 地点            前往地点
.注销 / 改名           注销 / 修改昵称
.购入 / 售出 / 买武器 / 武器商店   交易相关
.发展信众 / 教团信息 / 献祭       教团玩法
.逛逛 / 抢劫 / 翻垃圾 / 强行越狱 / 情报 / 行情   行动相关
.排行榜 / 个人信息 / 散播 / 丢弃 / 送 / 使用 / 转账
```
