# coc7指令中文版

- 源码：[coc7_cn.js](https://github.com/error2913/sealdice-js/blob/main/coc7_cn.js)
- 版本：1.0.0
- 作者：错误
- 依赖：内置 coc7 指令

## 简介

将内置 COC7 指令注册为中文别名，直接用中文指令使用对应的英文功能。

## 指令别名

| 别名 | 对应功能 |
| --- | --- |
| `.en` | 升级 |
| `.setcoc` | 设置房规 |
| `.ti` | 临时疯狂 |
| `.li` | 总结算 |
| `.ra` | 检定 |
| `.rav` | 对抗检定 |
| `.sc` | 理智检定 |
| `.coc` | 生成角色 |
| `.st` | 修改属性 |

## 备注

本质是将 `coc7` 扩展的指令映射为中文别名，指令帮助与行为与内置 COC7 一致。
