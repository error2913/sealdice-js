# 三骰联合延迟测试

- 源码：[ping_3d.js](https://github.com/error2913/sealdice-js/blob/main/ping_3d.js)
- 版本：1.0.2
- 作者：错误
- 依赖：无

## 简介

三个骰子同时安装并配置不同指令前缀时，测试各骰子之间的指令转发延迟。测试中请不要乱发指令。

## 指令

```text
【.乒 test <指令前缀a> <指令前缀b> <指令前缀c> <次数>】开始测试
    指令前缀a为接收指令的那个骰子，建议将 "." 替换成骰子a的专属前缀
【.乒 clr】重置测试（不能停止测试，停止测试请 bot off）
```
