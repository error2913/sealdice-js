# COC生成属性合并消息

- 源码：[coc_forward_msg.js](https://github.com/error2913/sealdice-js/blob/main/coc_forward_msg.js)
- 版本：1.0.2
- 作者：错误
- 依赖：ob11 网络连接依赖（>= 2.1.0）、内置 coc7 指令

## 简介

将内置 `.coc` 指令的生成结果合并为一条图文混排消息发送。目前仅有 NapCat 能使用。具体配置请查看插件设置。

## 插件设置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 合并消息预览 | `['{核心:骰子名字}: 属性已生成']` | 合并消息的标题模板 |
| 合并消息外部预览 | `['{核心:骰子名字}为{$t玩家}生成了属性']` | 合并消息的外显模板 |
| 聊天记录来源 | `['{核心:骰子名字}与{$t玩家_RAW}的聊天记录']` | 聊天记录转发来源 |

## 备注

本插件会修改内置指令 `.coc`，需要重启核心才能恢复原指令。
