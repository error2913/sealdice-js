# 非跑团群检测

- 源码：[non_trpg_group_detect.js](https://github.com/error2913/sealdice-js/blob/main/non_trpg_group_detect.js)
- 版本：1.0.2
- 作者：错误
- 依赖：无

## 简介

检测"跑团群沦为娱乐群"的插件。原理：进群后或使用跑团功能后，超过阈值时间再使用娱乐功能，则向通知列表告警。私聊或 `bot off` 时不会检测。配置均在插件设置中填写。

## 插件设置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 白名单群号 | `['']` | 不参与检测的群 |
| 跑团指令 | `['r','ra','rc','rh','sc','ri','log','setcoc','coc','dnd']` | 视为跑团行为的指令 |
| 跑团非指令正则表达式 | `['']` | 非指令形式的跑团消息匹配正则 |
| 娱乐指令 | `['jrrp']` | 视为娱乐行为的指令 |
| 娱乐非指令正则表达式 | `['']` | 非指令形式的娱乐消息匹配正则 |

## 备注

正则配置读取失败时插件会使用永不匹配的兜底正则，避免误报所有消息。
