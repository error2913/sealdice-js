# 集骰监听

- 源码：[集骰监听.js](../../集骰监听.js)
- 版本：1.0.1
- 作者：错误
- 依赖：无

## 简介

监听疑似"集骰"（同一条指令被多个骰子同时回复）的群，并把群号发给通知列表。极大可能误报，仅作参考。个性化设置请移步插件设置。

## 指令

```text
.monitor add 群号   添加白名单
.monitor del 群号   删除白名单
```

## 插件设置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 监听指令名称 | `['bot','r']` | 对这些指令的重复回复进行检测 |
| 计入消息模版 | `['SealDice\|Shiki\|AstralDice\|OlivaDice\|SitaNya','[Dd]\\d']` | 匹配到模版的消息才计入判定（支持正则） |

## 备注

- 白名单群号超过设定时间未发言后会被重新计入检测。
