# game（综合游戏框架）

- 目录：[game/](../../game/)
- 扩展名：game依赖
- 版本：1.0.0
- 作者：错误
- 依赖：无（作为其他插件的依赖使用）

## 简介

TypeScript 编写的综合游戏依赖框架，本身不提供直接指令，为其他插件（如[核弹发射按钮](核弹发射按钮.md)）提供基础能力。

## 模块

| 模块 | 说明 |
| --- | --- |
| `backpack` | 背包系统 |
| `shop` / `market` | 商店与市场（物价动态平衡） |
| `player` | 玩家数据管理 |
| `prop` | 道具系统 |
| `team` | 队伍系统 |
| `chart` | 图表统计 |
| `game` | 游戏管理器 |
| `vars` | 变量管理 |
| `utils` | 工具函数 |

## 构建

```bash
npm install
npm run build
```

产物输出到 `dist/`，放入海豹插件目录后重载。
