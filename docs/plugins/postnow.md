# 骰主公告极速版

- 源码：[postnow.js](https://github.com/error2913/sealdice-js/blob/main/postnow.js)
- 版本：1.2.0
- 作者：错误
- 依赖：可选 ob11 网络连接依赖（>= 2.1.0，HTTP 模式）

## 简介

让骰主掌握立即发公告、或者广告的权利。使用 `.pn help` 查看帮助（`.pnh` 为 HTTP 版旧指令，同样可用）。

插件自动选择工作模式：

- **HTTP 模式**：安装 ob11 网络连接依赖（>= 2.1.0）后自动启用，向当前账号的所有群发送公告，无需积累活跃数据。
- **普通模式**：未安装依赖时，仅发送给安装后一周内活跃过的群聊。

## 指令

```text
【.pn <公告内容>】发布公告，换行请使用 \n
【.pn emg <公告内容>】发布紧急公告，忽略是否处于 log 状态
【.pn chase <ID> <公告内容>】发布追杀公告，在特定用户活跃的群聊发送。ID格式: QQ:114514
【.pn chaseat <ID> <公告内容>】发布追杀公告，且@对应玩家
【.pn save】保存数据
【.pn send】确认发送
【.pn cancel】取消发送
```

## 备注

- 每四个小时自动储存一次数据，期间重载 JS 可能导致数据丢失，可使用 `.pn save` 手动保存。
- 活跃群/成员数据持续记录，供普通模式及群名片修改器使用。
- 依赖骰主公告极速版数据接口的插件（如群名片集体修改器）通过 `globalThis.getPostData()` 读取。
