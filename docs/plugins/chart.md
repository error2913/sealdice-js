# 排行榜

- 目录：[chart/](https://github.com/error2913/sealdice-js/tree/main/chart/)
- 扩展名：排行榜
- 版本：1.2.0
- 作者：错误
- 依赖：HTTP依赖（用于更新数据）

## 简介

TypeScript 编写的排行榜图表插件，将指定的变量数据同步并生成排行榜。

## 指令

```text
【.chart <变量名称>】查看排行榜
【.chart update】全部数据更新，需要 http 功能
```

## 插件设置

| 配置项 | 说明 |
| --- | --- |
| 变量同步指令名 | 用于触发变量同步的指令 |

## 构建

```bash
npm install
npm run build
```
