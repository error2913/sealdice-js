# 穗好感

- 源码：[sui_favorability.js](https://github.com/error2913/sealdice-js/blob/main/sui_favorability.js)
- 版本：1.0.1
- 作者：错误(2913949387)
- 依赖：无

## 简介

角色好感度插件，可查看好感度排行榜、签到获取好感、查看行囊等。

## 指令

```text
.好感排行榜   查看好感度排行
.查看行囊     查看背包
.签到         签到
```

## 备注

- 扩展名称为 `穗`，变量与数据均以扩展内存储方式保存。
- 源码中 `闲逛` 指令处于注释状态，未启用。
