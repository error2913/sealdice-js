# 群名片集体修改器

- 源码：[rename.js](../../rename.js)
- 版本：1.0.1
- 作者：错误
- 依赖：骰主公告极速版（>= 1.1.0）、deck 牌堆扩展

## 简介

批量修改群内成员群名片。七天内发言的用户才可被修改。骰娘和指令使用者都需要管理员权限。使用 `.rn` 获取帮助。

## 指令

```text
【.rn <模板>】将群成员的群名片设置为【模板】
【.rn pefix <前缀>】为群名片添加前缀
【.rn suffix <后缀>】为群名片添加后缀
【.rn fmt <前缀> <后缀>】为群名片添加前缀和后缀
【.rn draw】将群成员的群名片设置为牌堆抽取结果
【.rn amon】阿蒙！
【.rn clr】恢复群名片
```

## 备注

- 依赖 `deck` 牌堆扩展用于 `.rn draw`。
- 依赖骰主公告极速版获取群内活跃用户名单。
